# wordsearch-game
ESL word search game for a defined vocabulary words list

## ESL Word Search Generator

Open [word-search-game.html](./word-search-game.html) directly in a web browser. Enter vocabulary words separated by commas or new lines, then select **Generate Word Search**. Students can drag across a word or tap its first and last letters. After finding every word, they can reveal two sets of CLB 2/3 example sentences.
